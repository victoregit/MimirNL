# Code of conduct

Treat collaborators respectfully. Critique code and evidence rather than people. Harassment, threats, discrimination, doxxing and publishing private project data are unacceptable. Respect consent and keep sensitive memory contents out of public discussions.

Project maintainers may remove abusive content, close disruptive discussions or restrict participation proportionately. Describe concerns to the project owner through an existing trusted private contact if one is already available. No dedicated moderation address or private reporting service is configured or promised. If no private contact exists, request a contact route without disclosing personal or sensitive details. Maintainers involved in a report should not decide their own complaint where another maintainer is available.

This policy applies to project contribution and discussion spaces; it does not establish an emergency response service.
